# 图片资源目录

把图片按下面的路径和文件名放进来，**重新运行/打包就会自动生效**，不需要改任何代码。
没有放图片时，游戏会自动回退到内置的“渐变色 + 符号”画面，不会报错、不会空白。

## 目录与命名

```
images/
├── cards/                    卡牌图片
│   ├── m1.png                按「卡牌 id」命名（推荐）：m1 m2 m3 m4 m5 m6
│   ├── s1.png                法术卡：s1 s2
│   ├── p1.png                宠物卡：p1 p2
│   ├── 幼龙.png              也支持按「卡牌名称」命名（id 找不到时再按名称找）
│   └── frame.png             卡框叠加层（可选）：会盖在卡图之上，整张卡牌大小
├── heroes/
│   ├── player.png            玩家英雄头像（可选）
│   └── ai.png                AI 英雄头像（可选）
└── backgrounds/
    └── board.jpg             战场背景（可选，铺满整个窗口）
```

## 规格建议

| 用途 | 建议尺寸 | 格式 | 说明 |
|---|---|---|---|
| 卡图 `cards/*` | 256×256 或 320×240 | PNG（透明背景更好） | 会按 94×62 的比例填满卡图区，**建议按 3:2 出图**避免拉伸 |
| 卡框 `cards/frame.png` | 236×316（即卡牌的 2 倍图） | PNG 透明 | 整卡尺寸，会缩放到 118×158 |
| 英雄头像 `heroes/*` | 512×512 | PNG 透明 | 会被裁成圆形显示 |
| 战场背景 `backgrounds/board` | 1920×1080 | JPG 或 PNG | 会拉伸铺满窗口，暗色调更贴合主题 |

## 说明

- 支持格式：PNG / JPG（JavaFX 原生）。**WebP 不支持**，需要先转成 PNG。
- 同名 `.png` 优先于 `.jpg`。
- 图片是打包进程序里的：换图后需要重新运行（开发）或重新打包（分发）。
- 如果想让图片**在程序外面、方便随时替换**，告诉我，我可以改成从程序目录的 `images/` 文件夹读取。
