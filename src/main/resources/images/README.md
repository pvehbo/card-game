# 图片资源目录（v1.5 规范冻结版）

把图片按下面的路径和文件名放进来，**重新运行/打包就会自动生效**，不需要改任何代码。
没有放图片时，游戏会自动回退到内置的“渐变色 + 符号”画面，不会报错、不会空白。

> v1.5 冻结规格：卡图 512×716、头像 256×256、背景 1920×1080。
> 实际尺寸已用 `sips` 逐项核验，见 `docs/ASSETS-v1.5.md`。

## 目录与命名

```
images/
├── cards/                    卡牌图片（30 种，文件名 = 卡牌 id，见下表）
│   ├── m1.png … m17.png      随从卡（17 种）
│   ├── s1.png … s8.png       法术卡（8 种）
│   ├── p1.png … p5.png       宠物卡（5 种）
│   └── frame.png             卡框叠加层（可选）：会盖在卡图之上，整张卡牌大小
├── heroes/
│   ├── player.png            玩家英雄头像（256×256）
│   └── ai.png                AI 英雄头像（256×256）
└── backgrounds/
    ├── board.jpg             战场背景·暗主题（默认，1920×1080）
    └── board-light.jpg       战场背景·亮主题（1920×1080）
```

查找顺序（`ui/Assets.java`，先命中先生效）：
`cards/<id>.png` → `cards/<id>.jpg` → `cards/<名称>.png` → `cards/<名称>.jpg` → 程序化卡面。
同理：`heroes/<player|ai>.png` → `.jpg`；背景固定找 `backgrounds/board.png` → `board.jpg`。

## 规格（v1.5 冻结，勿随意改）

| 用途 | 冻结尺寸 | 格式 | 说明 |
|---|---|---|---|
| 卡图 `cards/<id>.png` | 512×716（≈5:7 炉石比例） | PNG（透明背景更好） | 会按卡图区比例填充；统一按此尺寸出图避免拉伸 |
| 卡框 `cards/frame.png` | 236×316（即卡牌的 2 倍图） | PNG 透明 | 整卡尺寸，会缩放到 118×158 |
| 英雄头像 `heroes/*` | 256×256 | PNG 透明 | 会被裁成圆形显示 |
| 战场背景 `backgrounds/board*.jpg` | 1920×1080 | JPG | 会拉伸铺满窗口，暗色调更贴合默认主题 |

## 说明

- 支持格式：PNG / JPG（JavaFX 原生）。**WebP 不支持**，需要先转成 PNG。
- 同名 `.png` 优先于 `.jpg`。
- 图片是打包进程序里的：换图后需要重新运行（开发）或重新打包（分发）。
- 删除任意图片后游戏照常启动，对应位置回退到程序化图形（`AssetsCoverageTest` 锁定了“30 种卡都有图”的基线；删图冒烟时可临时跳过该测试）。
- 如果想让图片**在程序外面、方便随时替换**，告诉我，我可以改成从程序目录的 `images/` 文件夹读取。
