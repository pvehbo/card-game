## 香草公式（BalanceCheck）

- 随从（cost>0）：`攻击+血量+2×战斗关键词数 ≈ 2×费用+2`，差值超 3 告警
- 法术：伤害 ≤ 费用+2；治疗 ≤ 2×费用；过牌张数 ≤ 费用
- 宠物：`|攻|+|血|` ≤ 费用+2
- 0 费基础卡免检（祖传数值，保持不动）
