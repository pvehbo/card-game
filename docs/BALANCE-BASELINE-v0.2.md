# 标准模式基线报告（自动生成）

> 生成器：`StandardBaselineSim`；每组 250 对换边种子（500 局）；整轮上限 30。

## 为什么要跑三种策略

同一套牌在“无脑交换 / 节奏 / 无脑打脸”下的胜率可能反向。只报一种策略会把 AI 偏好误当成卡牌强度，因此这里同时给出区间。

## 口径

- 一轮 = 双方各完成一个玩家回合；轮内斩杀计入本轮。
- 双归零 = 平局；打满上限未终局 = 超限，不按血量补造胜者。
- 决定局胜率 = A 胜 /（A 胜 + B 胜），平局与超限不入分母。
